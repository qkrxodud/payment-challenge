# 4장 결과 모름 보정 측정 (./gradlew reconciliationMeasurement, 태그 ch04)
# 결제 12건: 카드사가 1.5초 뒤 승인 4건, 1.5초 뒤 거절 3건, 승인 요청이 닿지 않음(LOST) 3건, 카드사 승인 뒤 결과 기록 실패(MySQL 트리거) 2건.
# 승인 읽기 시간 제한 1초. 카드사가 처리를 마친 뒤 보정을 돌리고, 보정에 넘기는 시각은 보정 대기 시간(10초)이 지난 때로 준다.
# 따라서 아래 시간에는 보정 대기 시간과 주기(interval)가 들어 있지 않다. 운영에서는 wait-after-request + interval 이 더해진다.
# "첫 보정의 확인 요청에 늦게 답함": 첫 보정 동안만 카드사가 조회·취소에 1.5초 뒤 답한다(읽기 시간 제한 1초를 넘김). 둘째 보정부터 바로 답한다.
# 보정은 미확정 결제(인증·결과 모름)가 남아 있으면 최대 5번까지 돌린다. "보정 횟수 5번"에 미확정 결제가 남았으면 5번 돌고도 확정하지 못한 것이다.
# 비교 B·C 는 보정이 없어 5번 모두 아무것도 하지 않은 시간이다.
# 실행 환경은 environment.md. 한 번 실행한 값이다.
