# 결제 12건(모두 15000원 승인 결제, 부분 취소는 5000원), 고객이 뜻한 카드사 취소 14건:
#   같은 금액 부분 취소를 키를 바꿔 두 번 2건(뜻한 취소 4) / 부분 취소 뒤 같은 키로 다시 2건(2) /
#   카드사 취소 답이 늦어 시간 초과, 그 뒤 보정만 2건(2) / 시간 초과, 카드사가 처리를 마친 뒤 같은 키로 다시 2건(2) /
#   카드사 취소 뒤 결과 기록 실패(MySQL 트리거), 그 뒤 보정만 2건(2) / 전액 취소 뒤 같은 키로 다시 2건(2)
# 읽기 시간 제한 1초, 늦은 취소는 1.5초 뒤에 답한다. 묶음을 다 보낸 뒤 보정을 한 번 돌리고, 보정에 넘기는 시각은 보정 대기 시간(10초)이 지난 때로 준다.
# "우리 남은 금액" = 결제 금액 - 끝난(DONE) 취소의 합. "카드사 잔액" = Mock PG 의 balanceAmount.
# "카드사가 받은 취소 요청"에는 같은 멱등키로 다시 와 Mock PG 가 처음 응답을 돌려준(다시 취소하지 않은) 요청도 들어 있다.
# 구현 순서는 실행 순서가 아니라 보기 쉽게 다시 늘어놓은 것이다. 실행 환경은 environment.md. 한 번 실행한 값이다.
